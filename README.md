# Customer Churn Prediction — AI Agent & Dashboard

An end-to-end customer churn project: a trained machine learning model,
an AI agent that can answer business questions about churn in natural
language, an interactive Streamlit dashboard, and a Power BI dashboard.

## What's provided vs. what you build

| Component | Status |
|---|---|
| Dataset (`data/`) | ✅ Provided |
| ML training pipeline (`src/train_model.py`) | ✅ Provided — do not modify |
| Prediction utilities (`src/predict.py`) | ✅ Provided — do not modify |
| AI Agent (`agent/`) | ✅ Working starter — **extend it** |
| Streamlit dashboard (`app/`) | ✅ Working starter — **extend it** |
| Power BI dashboard (`powerbi/`) | ⬜ **You build this**, data + guide provided |
| Deployment to Streamlit Cloud | ⬜ **You do this** |

## Quick start

```bash
git clone <your-repo-url>
cd customer-churn-ai-project
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 1. Train the model (generates models/*.pkl)
python src/train_model.py

# 2. Set up your API key
cp .env.example .env   # then paste your Anthropic API key into .env

# 3. Run the app
streamlit run app/streamlit_app.py
```

See **STUDENT_GUIDE.md** for the full walkthrough, including GitHub
setup and Streamlit Cloud deployment.

## Dataset

Telecom customer churn dataset — 850 customers, 34 attributes
(demographics, contract/billing, service usage, support interactions,
satisfaction scores) with a binary `churn` target. Full column
definitions are in `data/data_dictionary.csv`.

## Model

`src/train_model.py` trains and compares four models (Logistic
Regression, Decision Tree, Random Forest, Gradient Boosting) and
automatically selects the best one by ROC-AUC. Metrics for every
model are saved to `models/model_metrics.json`.
