# Power BI Dashboard Guide

Power BI (`.pbix`) files can't be generated by code — you build the
report yourself in Power BI Desktop, using the pre-scored data
provided here. This guide gets you from zero to a finished dashboard.

## 1. Data source

Use `powerbi/churn_dashboard_export.csv` — this is the full customer
dataset **already scored** by the trained model (it includes
`churn_probability` and `risk_tier` columns in addition to all the
raw customer attributes).

> This file is a snapshot. If you retrain the model or the dataset
> changes, regenerate it by running:
> `python -c "import sys; sys.path.append('src'); from predict import ChurnPredictor; ChurnPredictor().load_full_dataset_scored().to_csv('powerbi/churn_dashboard_export.csv', index=False)"`

## 2. Import into Power BI Desktop

1. Open Power BI Desktop → **Get Data** → **Text/CSV**
2. Select `churn_dashboard_export.csv`
3. Click **Load** (no transforms needed — the file is already clean)

## 3. Suggested pages & visuals

**Page 1 — Executive Overview**
- Card visuals: Total Customers, Actual Churn Rate %, Predicted High-Risk Count, Revenue at Risk
- Donut chart: `risk_tier` distribution
- Bar chart: churn rate by `contract_type`
- Bar chart: churn rate by `internet_service`

**Page 2 — Customer Risk Explorer**
- Table/matrix: `customer_id`, `churn_probability`, `risk_tier`, `monthly_charges`, `tenure_months`, `customer_service_calls`, sorted descending by `churn_probability`
- Slicers: `contract_type`, `location`, `payment_method`, `risk_tier`
- Scatter chart: `tenure_months` (x) vs `churn_probability` (y), colored by `risk_tier`

**Page 3 — Segment Deep Dive**
- Bar charts: churn rate by `payment_method`, `education_level`, `marital_status`
- Line/area chart: `customer_satisfaction_score` vs churn rate
- Heatmap/matrix: `contract_type` x `internet_service` average `churn_probability`

## 4. Suggested DAX measures

```DAX
Total Customers = COUNTROWS('churn_dashboard_export')

Actual Churn Rate % =
DIVIDE(
    CALCULATE(COUNTROWS('churn_dashboard_export'), 'churn_dashboard_export'[churn] = "Yes"),
    [Total Customers]
)

High Risk Customers =
CALCULATE(COUNTROWS('churn_dashboard_export'), 'churn_dashboard_export'[risk_tier] = "High Risk")

Revenue at Risk =
CALCULATE(
    SUM('churn_dashboard_export'[monthly_charges]),
    'churn_dashboard_export'[risk_tier] = "High Risk"
)

Avg Churn Probability = AVERAGE('churn_dashboard_export'[churn_probability])
```

## 5. Publishing

- **File → Publish → Publish to Power BI** (needs a Power BI account), or
- Export a static snapshot: **File → Export → PDF** to include in your report, or
- Take screenshots of each page to embed in your GitHub README / Streamlit app.

## 6. What to submit

- The `.pbix` file itself (add it to your repo under `powerbi/`)
- 2–3 screenshots of key pages (for the README and presentation)
